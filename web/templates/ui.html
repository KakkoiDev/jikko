This workspace is empty

Jikko reads Markdown files from the workspace directory on the host; there are none yet. Three steps make it usable:

  1. Create an identity page for yourself on the host, so Jikko knows who you are. A file alice.md holding 
    ---
type: identity
---
# Alice
    is enough. Groups are identities with a members list.
  2. Create a token with jikko auth create alice on the host and paste it into the login form above. Tokens are stored hashed in .auth.md, which stays out of Git.
  3. Write pages. Once logged in, New page creates documents, tasks and identities here; on the host, jikko create does the same, and any Markdown file dropped into the directory is a page too. Pages without a permissions mapping are open to everyone; jikko perm restricts them.

The list refreshes on its own as files appear.
