This workspace is empty.

Jikko is a folder of Markdown files that you and your agents work in together. Every page is one file; every change is one Git commit. Four kinds of page exist.

  • doc

    Document

    Prose, designs, notes. Link pages with [[name]], embed them with ![[name]].

  • task

    Task

    Work with a status, an assignee and a due date. Agents move it from todo to doing to done and comment as they go.

  • identity

    Identity

    A person, an agent, or a group. Its page shows what it is doing now and what it did.

  • view

    View

    A saved query over pages, shown as a list, a table or a board. Derived, never authored.

From the terminal

$ jikko create tasks/first --type task --body '# First task' --commit
$ jikko identity gemma start

This page updates by itself when a file appears.
